TUI 设置

CLI 设置只管终端客户端（TUI / mini）本身的外观与行为，和服务器端、项目级的 opencode.json(c) 设置是分开的两套。本页逐项列出 cli.json 的全部可用配置。

🧠 通俗理解

OpenCode 的配置分三层：opencode.json 是「项目章程」（模型、agent、权限，跟着项目走），而 cli.json 是「你的个人仪表盘设置」（主题、光标、滚动速度，跟着你的终端走）。改字体大小不影响发动机，改的是座椅和后视镜。

快速修改

在 TUI 里按 Ctrl+P，选择 Open settings，即可在界面中直接修改常用设置（打开后是一个设置对话框，无需手写 JSON）。

配置文件

OpenCode 把 CLI 设置存放在一个全局文件里：

路径
~/.config/opencode/cli.json

如果设置了 $XDG_CONFIG_HOME，则使用：

路径
$XDG_CONFIG_HOME/opencode/cli.json

没有项目级的 CLI 设置文件——这套配置永远是全局的。加上官方发布的 JSON Schema 即可获得校验和自动补全：

cli.json
{
  "$schema": "https://opencode.ai/v2/cli.json"
}

OpenCode 在首次创建或迁移这个文件时会自动写入 $schema。TUI 运行期间的有效修改会热重载。未知的设置项会被忽略；保留 $schema，编辑器就能标出无效值。

⚠️ 注意

两套配置别混着写：模型、agent、MCP 服务器这些要写进项目里的 opencode.json（见配置一章），写进 cli.json 是不生效的；反过来主题、快捷键这类只认 cli.json。手改 cli.json 时务必保留 $schema 字段，否则编辑器不会帮你检查拼写错误，而 OpenCode 对未知键只是静默忽略——写错了不会有任何报错提示。

内联配置

设置环境变量 OPENCODE_CLI_CONFIG_CONTENT，可以用内联 JSON 临时应用 CLI 设置：

sh单次启动生效
OPENCODE_CLI_CONFIG_CONTENT='{"tabs":{"mode":"off"}}' opencode

内联设置会合并到全局 cli.json 之上：嵌套对象做深层合并，而数组和标量值会直接替换全局值。只要这个变量还在，内联设置就始终优先。

外观

选择主题、控制界面动效、覆盖终端光标样式：

cli.json
{
  "theme": {
    "name": "tokyonight",
    "mode": "system"
  },
  "animations": true,
  "cursor": {
    "style": "block",
    "blinking": true
  }
}
设置项可选值说明
theme.name字符串选择内置主题、自定义主题或从终端提取的主题。
theme.modesystem / dark / light跟随终端外观，或将主题锁定为单一明暗模式。
animations布尔值是否启用界面动画。
cursor.styleblock / underline / line / default设置光标形状。default 表示保留终端自己的光标形状。
cursor.blinking布尔值控制光标闪烁。当 style 为 default 时此项无效。

主题的选择与创建见TUI 主题一页。

输入

配置鼠标捕获、滚动、编辑器上下文、粘贴行为和 prompt 图片预览：

cli.json
{
  "mouse": true,
  "scroll": {
    "speed": 3,
    "acceleration": false
  },
  "prompt": {
    "editor": true,
    "paste": "compact",
    "image_preview": false
  }
}
设置项可选值说明
mouse布尔值是否启用终端鼠标捕获。
scroll.speed数字，最小 0.001每次滚动输入的固定滚动距离。
scroll.acceleration布尔值连续滚动时加速。启用后优先于 speed。
prompt.editor布尔值是否把当前编辑器打开的文件或选区作为 prompt 上下文。
prompt.pastecompact / full大段粘贴内容显示为紧凑占位符，还是显示全文。
prompt.image_preview布尔值是否在 prompt 输入框上方显示图片附件预览。

会话

配置全屏 TUI 会话的呈现方式，以及新会话的起始位置：

cli.json
{
  "session": {
    "sidebar": "auto",
    "scrollbar": false,
    "submit_scroll": "bottom",
    "thinking": "hide",
    "grouping": "auto",
    "image_preview": false,
    "tps": true,
    "markdown": "rendered",
    "new_location": "launch",
    "permissions": "prompt"
  }
}
设置项可选值说明
session.sidebarauto / hide空间够时显示侧边栏，或始终隐藏。
session.scrollbar布尔值是否显示对话记录滚动条。
session.submit_scrollbottom / keep发送 prompt 时跳到最新消息，还是保持当前位置。
session.thinkingshow / hide默认显示或隐藏模型推理过程。
session.groupingauto / none把相关对话条目分组呈现，还是逐条独立渲染。
session.image_preview布尔值是否在对话记录中显示用户附件和工具结果的图片。
session.tps布尔值是否在助手消息底部显示每秒输出 token 数。
session.markdownsource / rendered显示 Markdown 源码标记，还是隐藏标记、显示渲染后的效果。
session.new_locationlaunch / inherit新会话从 TUI 启动目录开始，还是继承当前活动会话的位置。
session.permissionsprompt / autoaccept权限请求逐个弹窗询问，还是自动接受每个请求。

⚠️ 注意

session.permissions: "autoaccept" 意味着模型执行任何命令、改任何文件都不再问你——只建议在一次性容器、专用虚拟机或完全可控的沙箱里使用。日常开发请保持 "prompt"，更细粒度的权限规则请配置在项目的 opencode.json 权限部分，而不是这里。

标签页

配置常驻的会话标签栏：

cli.json
{
  "tabs": {
    "mode": "auto",
    "scope": "cwd",
    "layout": "horizontal",
    "indicators": "status"
  }
}

旧的布尔值 tabs.enabled 依然兼容：true 等价于 on，false 等价于 off。OpenCode 会直接读取它，不会改写你的配置文件。

设置项可选值说明
tabs.modeauto / on / off自动使用、始终使用或从不使用标签页。auto 模式下在 Herdr 中会自动隐藏。
tabs.scopecwd / global按工作目录各留一套标签，还是全局共享。
tabs.layouthorizontal / vertical标签排成横向条，还是纵向侧栏。
tabs.indicatorsstatus / numbers显示状态图标，还是始终显示标签编号。

编号指示依然保留状态颜色和背景动画。两种模式下都可以用 Ctrl+数字 快捷键切换标签。

Diff 视图

配置 diff 的初始范围和呈现方式：

cli.json
{
  "diffs": {
    "source": "branch",
    "wrap": "word",
    "tree": true,
    "single": false,
    "view": "auto"
  }
}
设置项可选值说明
diffs.sourcebranch / committed / working / turn设置初始审查范围。
diffs.wrapword / none长行按单词折行，还是不折行。
diffs.tree布尔值是否显示 diff 文件树。
diffs.single布尔值是否只显示选中文件的补丁。
diffs.viewauto / split / unified布局方式。auto 会根据可用宽度自动选择。

branch 显示整个分支及本地改动（All）；committed 只显示分支上的提交；working 显示已暂存、未暂存和未跟踪的改动。turn 显示 Last turn，即会话在最近一轮中改动的文件——会话每完成一轮就刷新；当 /diff 不是从会话里打开时，会退回到 branch。

在 /diff 视图中按 d 可以切换范围，或从 Base 中选择一个对比分支。这些视图内的选择只在本次 TUI 会话中有效，不会写入 cli.json。

提醒

系统通知和提示音可以独立开关：

cli.json
{
  "attention": {
    "notifications": true,
    "sound": true,
    "volume": 0.4,
    "sound_pack": "opencode.default",
    "sounds": {
      "permission": "/home/me/sounds/permission.wav"
    }
  }
}
设置项可选值说明
attention.notifications布尔值显示系统通知，通常只在终端未聚焦时触发。
attention.sound布尔值播放提示音。
attention.volume0 到 1 的数字设置音量。
attention.sound_pack字符串选择当前生效的音效包 ID。
attention.sounds对象按事件覆盖音效文件，可选事件：default、question、permission、error、done、subagent_done。

无效或不可读的覆盖文件会回退到该事件的内置音效。

更新亮点弹窗

OpenCode 更新后，TUI 会在主页一次性显示本次发布的新功能亮点。想再看一次可运行 /highlights，或者彻底关掉这个弹窗：

cli.json
{
  "highlights": false
}

终端集成

配置与终端本身相关的行为：

cli.json
{
  "terminal": {
    "title": true,
    "copy": "select"
  }
}
设置项可选值说明
terminal.title布尔值是否更新终端窗口标题。
terminal.copymanual / select手动复制，还是选中即复制。平台默认值：Windows 为 manual，其它平台为 select。

Mini 界面

mini 配置组控制 opencode mini 极简交互界面：

cli.json
{
  "mini": {
    "thinking": "show",
    "tools": "hide",
    "shell_output": "hide",
    "turn_summary": "show",
    "footer": "show",
    "splash": "show",
    "work_spinner": "block-soft-slide",
    "mono": false,
    "replay": true,
    "replay_limit": 200
  }
}
设置项可选值说明
mini.thinkingshow / hide显示或隐藏模型推理过程。
mini.toolsshow / hide显示或隐藏工具调用及其前面的助手文字。
mini.shell_outputshow / hide显示或隐藏 shell 工具的原始输出。
mini.turn_summaryshow / hide显示或隐藏滚动记录中的 agent、模型与耗时摘要。
mini.footershow / hide显示或隐藏常驻的活动状态、模型、用量与上下文信息。
mini.splashshow / hide显示或隐藏进入和退出的横幅画面。
mini.work_spinnerspinner ID选择页脚的工作状态动画。
mini.mono布尔值使用单色 ASCII 输出。
mini.replay布尔值恢复会话时以及终端尺寸变化时重放历史记录。
mini.replay_limit正整数限制重放的消息条数（只重放最新的）。默认上限 200。

可用的 spinner ID 有：

text
block-soft-slide  block-soft-sweep  block-low-comet  block-low-duet
block-shuttle     block-bridge      block-squeeze    small-toggle
square-toggle     grow-shrink       quadrant-orbit   crosshatch
density-wave      seed

命令行上给 mini 传的重放（replay）参数会覆盖这些设置，但仅对该次调用生效。

快捷键

可以覆盖某个命令的键绑定和前导键超时：

cli.json
{
  "keybinds": {
    "leader": "ctrl+x",
    "app.exit": ["ctrl+c", "ctrl+d", "<leader>q"],
    "prompt.paste": {
      "key": "ctrl+v",
      "event": "press",
      "preventDefault": false,
      "fallthrough": false
    },
    "help.show": false
  },
  "leader": {
    "timeout": 2000
  }
}
设置项可选值说明
keybinds.leader绑定值设置其它绑定中 <leader> 引用的按键。
keybinds.<command>绑定值覆盖单个命令 ID 的绑定。
keybinds.*.key按键字符串或描述符为对象形式的绑定选择按键。
keybinds.*.eventpress / release将对象绑定限制在单一按键事件上。
keybinds.*.preventDefault布尔值控制是否阻止终端对该键的默认行为。
keybinds.*.fallthrough布尔值允许优先级更低的处理器也接收同一事件。
leader.timeout正整数设置按下前导键之后的等待毫秒数。

绑定值可以是字符串、备选按键数组，或对象。用 "none" 或 false 可以禁用某个绑定。按键语法、全部命令 ID 和全部默认绑定见快捷键一页。

插件

按顺序加载仅限终端客户端使用的插件：

cli.json
{
  "plugins": [
    "-opencode.notifications",
    {
      "package": "./plugins/status",
      "options": {
        "compact": true
      }
    }
  ]
}
设置项可选值说明
plugins数组声明按顺序排列的启停指令和外部插件。
plugins[].package字符串包名、本地路径或 file URL。
plugins[].options对象传给该插件的专属选项。

包的写法、本地发现、通配符和禁用指令详见TUI 插件一页。

调试与实验性功能

开启诊断选项，或主动加入当前可用的实验：

cli.json
{
  "debug": {
    "devtools": false,
    "timing": false,
    "turn_tokens": "verbose"
  },
  "experimental": {}
}
设置项可选值说明
debug.devtools布尔值显示 DevTools 调试栏。
debug.timing布尔值在调试栏中显示首次绘制耗时诊断。
debug.turn_tokens布尔值或 verbose显示每轮的 token 用量；verbose 还会包含工具调用输入。
experimental功能 ID → 布尔值的对象启用或禁用实验功能。这些功能可能随时变化或移除，不另行通知。

💡 扩展

experimental 里只应填写 TUI 的 Experiments 对话框中当前列出的功能 ID，未知 ID 没有任何效果。实验功能是官方在正式发布前的「试吃装」——不稳定、可能随时改接口，但能提前体验新特性。日常开发不建议开启，除非你在跟进某个具体的新特性。
