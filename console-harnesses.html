Harnesses

Console 不仅能配合 OpenCode，也能配合其它编码智能体使用。把一个 Harness（接入层）指向 Console 网关并配好 API key，就能使用所有付费模型或 Go 模型，用量照常计入你的工作区。

🧠 通俗理解

「Harness」直译是「马具」——把现成的编码工具（比如 Claude Code、Codex）「套上缰绳」，接到 OpenCode 的模型供给上：工具还是那个工具、交互习惯不变，但底层跑的模型变成了你工作区里的付费模型或 Go 订阅模型。一次配置，既有大厂工具的体验，又有 Console 的计费、策略（policies）和 MCP 服务器托管，两全其美。

⚠️ 注意

免费档的 chat 模型只能在 OpenCode 客户端内使用。其它 Harness 即使带着 Console API key 访问这些模型，也会收到 HTTP 403。想在第三方工具里跑，请使用付费模型或 Go 订阅。

Console CLI

Console CLI 可以用一条命令把 Harness 连接到你的工作区。它需要 Node.js 22 或更高版本。

Harness命令
Claude Codenpx @opencode/console setup claude-code
Codexnpx @opencode/console setup codex
Hermesnpx @opencode/console setup hermes
Pinpx @opencode/console setup pi
DeepSeek Harnessnpx @opencode/console setup deepseek-harness

执行后浏览器会打开 Console，你在里面批准登录并选择工作区。之后这个 Harness 就会获得：

  • 工作区的模型，经由 Console 提供
  • 工作区的策略（policies），在每次工具调用之前检查
  • 工作区的 MCP 服务器、Skills 和指令文件（instructions）

CLI 会持续让 Harness 与工作区保持同步，并自动更新自身。

如果想让 Harness 保留它自己的登录方式和模型（比如你的 Claude 或 ChatGPT 订阅），加上 --keep-provider。Harness 仍会获得工作区的策略、MCP 服务器、Skills 和指令文件。此选项适用于 Claude Code、Codex 和 Hermes：

bash保留自带订阅
npx @opencode/console setup codex --keep-provider

想手动配置某个 Harness，或者 CLI 还不支持的 Harness，可以用 API key 加下文的 base URL。

获取 API key

Harness 用 Console API key 认证。最快捷的选择是个人 API key，它会以你的身份调用模型：

  1. 在 Console 的账号菜单里打开 Account。
  2. 在 Personal API keys 下，点击 Add API key。
  3. 选择工作区、给 key 起名，点击 Create。
  4. 复制 key。它只显示这一次。
textkey 的样例格式
oc_sk_1a2b3c4d5e6f_...

用量会计入你的成员预算（member budget）。要按量付费，请用有额度（credits）的工作区的 key；要用 Go，请用订阅了 Go 的工作区的 key。

在共享机器或 CI 上，Owner 和管理员可以改用服务账号（service account）的 key，这样用量就不会绑在某一个人身上。

按量付费和 Go 使用不同的 base URL，按你的套餐选用：

会话（Sessions）

每个请求都带上一个稳定的会话 ID，这样 Console 才能把同一段对话一致地路由，并复用它的提示缓存（prompt cache）。Go 要求必须带：

text
x-opencode-session: ses_...

Console 也能识别 Claude Code、Codex、Hermes 和 Pi 自带的原生会话 header，所以这些 Harness 无需额外配置。

💡 扩展

为什么会话 ID 重要？推理网关常用「提示缓存」省钱：同一对话的前缀内容只需处理一次，后续请求命中缓存就能大幅降低成本和延迟。要让缓存命中，同一段对话的请求必须被路由到同一处、并携带一致的会话标识——这就是 x-opencode-session 的作用。在 Go 套餐下它是硬性要求，缺了可能直接被拒。

Console MCP

支持 MCP 的 Harness 可以通过 Console MCP 服务器管理你的工作区。它使用 OAuth 动态客户端注册，你直接在浏览器里登录即可，不用粘贴 key：

text
https://opencode.ai/console/mcp

每个 Harness 的页面都说明了如何添加它。当你的工作区启用该服务器时，OpenCode 会自动把它添加为 opencode_console，并在首次使用时请你从浏览器登录。
