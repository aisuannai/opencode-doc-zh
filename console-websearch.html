网页搜索

Console 为已连接的 OpenCode 用户提供托管的网页搜索（hosted web search）。工作区所有者或管理员只需在工作区层面启用一次，成员无需各自配置搜索提供商的 API key。

🧠 通俗理解

正常接搜索能力，每个人都得去注册搜索 API、领 key、写配置。托管搜索把这一切变成「管理员开一次闸，全队直接用」：搜索请求由 Console 代发、代付（每次成功搜索 1 美分），计入工作区余额和成员的消费限额。对成员来说体验就是——聊天里问一句最新资讯，OpenCode 自己去搜。

启用

  1. 以工作区所有者或管理员身份登录控制台。
  2. 打开 Integrations，在 Hosted Web Search 上点击 Set up。
  3. 点击 Enable。

然后每位成员用 /connect 把 OpenCode 连接到工作区：

OpenCode 命令
/connect

工作区配置会把 OpenCode Web Search 设为默认搜索提供商。成员不需要设置 websearch.provider，也不需要添加提供商 API key。如果某个成员自己设置了 websearch.provider，则以他自己的选择为准。

搜索

在提示词里直接向 OpenCode 索要最新信息即可。搜索由 OpenCode 执行，而不是在 Console 的某个交互页面里进行。

提示词示例
Find the latest Bun release and summarize the changes with source links.

托管提供商搜索公共网络，最多返回八条结果。OpenCode 利用这些结果回答你的问题并引用来源。

要配置权限或禁用该工具，见网页搜索指南。

计费

搜索返回有效结果集后，Console 收取 $0.01。失败和被限流的搜索不收费。

网页搜索费用在 Activity › Usage、Activity › Overview、成员活动、发票和 CSV 导出中与模型用量分开列示。适用的全支出（all-spend）预算策略同样覆盖网页搜索费用。

隐私

托管网页搜索实行零数据保留（zero data retention）。Console 及其托管搜索提供商只处理每次查询及其结果，不存储其内容。

💡 扩展

「零数据保留」意味着你的搜索词不会成为训练数据或被长期留档，对处理敏感业务线索的场景比较友好。另外注意：搜索走的是公共网络，只能搜到公开网页——内部 wiki、私有数据库里的内容它碰不到，那种需求要靠 MCP 工具或本地检索来解决。
