HTTP API

OpenCode 服务器的 HTTP API 参考：针对所选实例路由的实验性 HttpApi 接口。本参考覆盖来自 OpenAPI 3.1.0 文档的 173 个操作和 518 个 schema。

🧠 通俗理解

这一页是 OpenCode 服务器的「菜单」：每个端点一行，标了 HTTP 方法、路径和一句话说明。前缀 /api/ 是常规路由，/api/experimental/ 或标注「实验性」的分组可能随版本变化。不想手写 HTTP 调用的话，可以直接用 客户端 (JS)——它的方法和类型就是从这份契约生成的。
