网页搜索

问 OpenCode 一个需要最新信息的问题，它可以搜索网页、阅读结果，并在回答里附上来源链接。搜索由 Exa、Tavily 等第三方服务商提供，需要一个 API 密钥。

直接提出需求即可：

text
Find the latest Bun release and summarize the changes.

第一次搜索时，OpenCode 会请你允许网页搜索并选择一个服务商（provider）。之后它会记住你的选择，供后续会话使用。

服务商（Providers）

OpenCode 内置五个搜索服务商：

服务商ID环境变量
ExaexaEXA_API_KEY
FirecrawlfirecrawlFIRECRAWL_API_KEY
ParallelparallelPARALLEL_API_KEY
TavilytavilyTAVILY_API_KEY
TinyFishtinyfishTINYFISH_API_KEY（可选）

两种接入方式任选：在 TUI 里用 /connect 连接账号，或在启动 OpenCode 之前设置对应的环境变量：

bash
$ TAVILY_API_KEY=your-key opencode

选择服务商（Selection）

在 opencode.jsonc 里指定服务商，可以跳过首次的选择提示：

opencode.jsoncJSONC
{
  "$schema": "https://opencode.ai/config.json",
  "websearch": {
    "provider": "tavily",
  },
}

设为 "random" 可以自动在可用服务商中选择。每个会话会一直用自己选定的服务商，直到该服务商被限流：

opencode.jsoncJSONC
{
  "$schema": "https://opencode.ai/config.json",
  "websearch": {
    "provider": "random",
  },
}

限流与重试（Limits）

当某个服务商返回 HTTP 429 时，random 模式会换另一个可用的服务商重试这次搜索。被限流的服务商进入冷却，等待自己的 Retry-After 时长；如果响应里没有有效的时长，就等 60 秒：

text流程示意
Exa returns HTTP 429
→ Exa enters cooldown
→ OpenCode retries with another provider

如果所有服务商都在冷却中，搜索会立即失败。把会话迁移走或重启它的服务器，会清掉会话记住的服务商；冷却状态由同一工作区中的所有会话共享。

权限（Permissions）

网页搜索使用 websearch 权限动作、搜索查询词作为资源。对未被显式允许的搜索，先询问再执行：

opencode.jsoncJSONC
{
  "$schema": "https://opencode.ai/config.json",
  "permissions": [
    {
      "action": "websearch",
      "resource": "*",
      "effect": "ask",
    },
  ],
}

规则顺序和匹配规则见 权限一章。

禁用（Disable）

把 websearch 设为 false，可以从模型请求中移除网页搜索工具：

opencode.jsoncJSONC
{
  "$schema": "https://opencode.ai/config.json",
  "websearch": false,
}

🧠 通俗理解

模型本身的训练数据有「截止日期」，问它「最新版本是什么」就会开始瞎编。网页搜索等于给智能体接了一根「网线」：先搜、再读结果、最后带出处回答。企业内网或合规要求下不想让它上网，就把 websearch 设为 false 一键拔线。
