简介与安装

OpenCode 是一个开源的 AI 编码智能体（coding agent）。它有三种形态：终端里的 TUI、桌面应用、以及 Web 界面。这一页讲清楚它是什么，以及怎么装到你的电脑上。

🧠 通俗理解

「编码智能体」和「代码补全」不是一回事。补全工具（比如早期的 Copilot Tab）是你写一句它接一句；而智能体是你描述目标，它自己拆任务、读代码、改文件、跑命令，做完再向你汇报。OpenCode 就是后者，而且它运行在你自己的终端里，代码不离开你的电脑（除非你选择连接云端模型）。

安装 CLI

CLI 是 OpenCode 最核心的形态，四种主流安装方式任选其一：

curl推荐 · 一行安装
curl -fsSL https://opencode.ai/v2/install | bash
homebrewmacOS / Linux
brew install anomalyco/tap/opencode-v2
npmNode.js 用户
npm install -g @opencode/cli
bun
bun install -g --trust @opencode/cli

此外还支持 pnpm、yarn、vite+、AUR（Arch Linux）和 mise：

其它包管理器
pnpm add -g --allow-build=@opencode/cli @opencode/cli
yarn global add @opencode/cli
vp install -g @opencode/cli          # vite+
paru -S opencode-beta                # Arch Linux (AUR)
mise use -g opencode                 # 需要 mise ≥ 2026.10.9

npm 包在安装时会通过 postinstall 脚本自动挑选适配你平台的 opencode 原生二进制；Bun 和 pnpm 的命令里显式放行了这个脚本（--trust / --allow-build）；vite+ 无需额外参数；mise 需要较新版本，旧版本 mise 装出来的会是 OpenCode 1.x。

⚠️ 注意

Windows 不支持包管理器安装方式。Windows 用户请用下面的「独立二进制下载」，或考虑 WSL 环境。

独立二进制下载

不想用包管理器，可以直接下载对应平台的可执行文件：

  • macOS：Apple 芯片 · Intel · Intel（基线版）
  • Windows：ARM64 · x64 · x64（基线版）
  • Linux (glibc)：ARM64 · x64 · x64（基线版）
  • Linux (musl)：ARM64 · x64 · x64（基线版）

💡 扩展

「基线版（baseline）」是针对老 CPU 的兼容构建：x64 芯片如果要支持 AVX2 之前的旧指令集，就用 baseline 版。如果你的机器较新（近十年的 x64 或任意 Apple Silicon / ARM64），普通版即可。glibc 和 musl 则是 Linux 两套不同的 C 标准库——Ubuntu/Debian/Fedora 用 glibc 版，Alpine 用 musl 版。

桌面应用

喜欢图形界面的话，下载对应平台的 OpenCode Desktop：

  • macOS：Apple 芯片 · Intel
  • Windows：x64 · ARM64
  • Linux (.deb)：x64 · ARM64
  • Linux (.rpm)：x64 · ARM64
  • Linux (AppImage)：x64

Web 界面

用 opencode pair 命令可以打开 Web 界面：

bash
$ opencode pair

  Open a link to connect. Links work once and expire in 5 minutes.

  http://127.0.0.1:49374/auth/connect/...

🧠 通俗理解

pair 的意思是「结对编程」：终端里的 OpenCode 在本地起一个一次性链接，你在浏览器里打开它，就能在网页上和同一个会话协作。链接只能用一次、5 分钟后过期，所以不用担心别人扫到这个端口就能蹭进来。

Docker

Docker 镜像使用带版本号的 tag，例如 ghcr.io/anomalyco/opencode:2.0.0。

连接模型

OpenCode 内置支持大量 LLM 提供商，可以在 TUI 里用 /connect 直接连接。要配置自定义提供商（比如中转 API 或本地模型），见 Providers 一章。

如果想要开箱即用的顶级编码模型，可以使用 OpenCode Console，或者选择 OpenCode Go——每月 10 美元的订阅方案，直接获得多个顶级编码模型的使用权。

个性化定制

装好之后，OpenCode 的几乎所有行为都可以改造：

  • 改 配置文件（模型、权限、行为）
  • 加载 插件，扩展 hook 和工具
  • 接入 MCP 服务器，获得海量现成工具
  • 创建自定义命令，把常用流程一键化

终端界面的主题和快捷键在 CLI 设置里配置。
