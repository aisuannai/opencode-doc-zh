Go 订阅

OpenCode Go 让你以固定的月费稳定使用热门开源编码模型，共三个档位。它专门面向国际用户设计，提供稳定的全球访问。

计划价格包含用量
Go$10/月以下模型的低成本使用权
Go Plus$40/月以下模型的更高用量上限
Go Teams$20/成员/月，最少 2 名成员每位成员有独立用量上限，每个模型都比 Go 高 $5/月

🧠 通俗理解

Go 和 Console 的按量付费（pay-as-you-go）是两种完全不同的付费哲学：按量付费像「打车」，跑一次付一次；Go 像「包月公交卡」，每月固定一笔钱，敞开用热门开源模型。在 OpenCode 眼里 Go 也是一个普通提供商——订阅后拿 API key，/connect 连上即可。它完全可选，不用它照样能用 OpenCode。最新模型名单见官网 Go 页面，可能会随测试和新模型加入而变化。

工作原理

  1. 登录 OpenCode 控制台，订阅 Go、Go Plus 或 Go Teams，填写账单信息，复制你的 API key。
  2. 在 TUI 里运行 /connect，选择 OpenCode Go，粘贴你的 API key。
OpenCode 命令
/connect
  1. 运行 /models 选择一个 Go 提供的模型。
OpenCode 命令
/models

⚠️ 注意

Go 和 Go Plus 只覆盖订阅者本人以及工作区的 API key。你邀请进来的其他成员只能用免费模型或工作区余额。双方都可以随时升级到 Go Teams，本月未用完的部分会折算成额度返还。Go Teams 覆盖工作区的每一位成员，$20/成员/月，最少 2 名成员（即 $40/月起）。第二个席位免费覆盖下一位加入的成员；之后，期中加入的成员按 $20 收费并获得完整的当月额度。服务账号（service accounts）不在 Go Teams 覆盖范围内。

启用受限模型

工作区的隐私设置同样约束 Go。默认情况下，会基于请求数据训练的付费端点被屏蔽，允许区域为「欧洲与美国（Europe & United States）」。未保存过隐私设置的工作区，对来自中国的请求也允许「全球（Global）」。

在 Settings › Privacy 中，所有者或管理员可以启用：

  • DeepSeek V4.1 Flash 和 V4 Pro：在 Regions 下选择 Global。
  • LongCat 2.5 Free：在 Regions 下选择 Global。
  • Muse Spark 1.3 Contributor 和 Muse Spark 1.2 Contributor：打开 Allow paid endpoints that train on request data（允许基于请求数据训练的付费端点）。

每个模型的训练与保留条款见下文隐私一节。

用额度支付

所有者和管理员可以用工作区额度（credit）支付 Go 的订阅费，包括续费和升级。订阅时选择 Credit 作为支付方式，或之后在 Manage subscription 中选择。这与 Extra Usage（用额度支付超出上限的用量）是两回事。

  • 全价从你的额度余额中扣除。余额不足时，可以先充值。
  • 续费在周期结束时从额度扣款。如果额度不够，Go 会保持可用，同时续费在周期结束后第 1、3、7 天重试，并且一旦充入足够额度立即重试。如果最后一次重试仍失败，Go 终止。
  • 使用发票账单（invoiced billing）的工作区不能用额度支付 Go。
  • 用额度支付的 Go 订单退款时，退款回到你的额度中，同时该 Go 周期结束。

可以在哪里使用？

OpenCode Go 为 OpenCode 以及产生类似请求的其他编码智能体设计。我们会监控滥用流量，避免影响其他用户的使用体验。

你的客户端应该：

  1. 发送典型的编码智能体流量。
  2. 用自己的 User Agent 标识自己，比如 my-coding-agent/1.0，而不是通用的 SDK 或 HTTP 库名称。
  3. 每个会话在 x-opencode-session 中发送稳定的会话 ID，方便我们优化路由和提示词缓存。

要在 Claude Code、Codex、Hermes、Pi、Raycast 中使用 Go，见 Harnesses 一章。

用量上限

你在 Go 上使用的付费模型共享同一份额度。Go Teams 上每位成员有自己的跨模型额度。

  • 5 小时上限：为你月度额度的 20%。窗口从你首次使用额度时开始，持续五小时。
  • 每周上限：为你月度额度的 50%。每周一 00:00 UTC 重置。
  • 月度额度：在新的付费周期开始时重置。

切换模型也消耗同一份额度。如果触达上限，你可以改用免费模型，或打开 Extra Usage 用你的 Console 额度继续使用，直到额度恢复。

每个模型的月度上限表示：如果整月只用这一个模型，你的计划能覆盖多少用量。例如，某模型上限 $15，你用了 $1.50，就消耗了月度额度的 10%；上限 $60 的模型用 $6，同样是 10%。Go 的响应会通过 opencode.allowance 报告每个请求消耗了多少额度。

Token 价格按每 1M tokens 计，Go、Go Plus、Go Teams 三档价格相同。

Beam Free：限时免费。在安哥拉、白俄罗斯、柬埔寨、中国（含香港和澳门）、古巴、刚果民主共和国、赤道几内亚、伊朗、伊拉克、老挝、利比亚、尼日利亚、朝鲜、俄罗斯、叙利亚、土库曼斯坦、乌兹别克斯坦、委内瑞拉，以及乌克兰的克里米亚、顿涅茨克和卢甘斯克地区不可用。

💡 扩展

触达用量上限时，你仍可以继续使用免费模型。用量上限可能会随着我们从早期使用和反馈中积累经验而调整。

超出上限后的用量

如果你的 Console 余额里还有额度，可以在 Go 页面打开 Extra Usage。启用后，当你触达用量上限时，Go 会退回到你的按量付费余额继续服务，而不是直接拦截请求。

Go Teams 默认开启 Extra Usage，你可以在 Go 页面关闭或重新打开。

为什么有些模型用量更低

在 Go 下，各模型包含的月度用量并不相同。

对大多数模型，我们靠批量折扣和预订 GPU 算力把成本压下来，再把省下的钱以更高的月度用量回馈给你。

对另一些模型，我们还没谈下折扣或更低成本的托管方式——可能是模型太新，也可能是它们的公开定价本身已经是折扣价。

对这些模型，你得到的用量仍略高于直接向模型厂商付费的情况；这正是它们包含的月度用量较低的原因。

端点

你也可以通过 API 在 https://opencode.ai/inference/go 访问 Go 模型。每个模型的 ID、路径和 AI SDK 包见 Go 页面。每个模型列出的是它的原生 API，但每个文本模型也都能通过其他 API 调用——Console 会自动转换。完整端点清单见 Base URLs。

这些 AI SDK 包是给直接调用 Go 的应用准备的。要在 OpenCode 里使用 Go，请先用 /connect 连接，然后按 opencode-go/<model-id> 格式设置模型：

opencode.jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "model": "opencode-go/kimi-k3",
}

模型列表

通过 models 端点拉取完整的可用模型列表及其元数据：

bash
curl https://opencode.ai/inference/go/v1/models

响应中每个字段的含义（包括 Go 的月度用量上限）见模型列表 API。

背景

开源模型已经变得非常强，在编码任务上的性能已逼近专有模型。而且因为多家提供商都能有竞争力地提供它们，价格通常便宜得多。

不过，要获得稳定、低延迟的访问并不容易——各提供商的质量和可用性参差不齐。

🧠 通俗理解

OpenCode 团队测试了一批与 OpenCode 配合良好的模型和提供商，而不是把全市场模型一股脑塞给你。换句话说，这份名单是「预筛选 + 基准测试」的产物，不是简单转发。

为解决这个问题，我们做了几件事：

  1. 测试了一批精选的开源模型，并与模型团队沟通最佳运行方式。
  2. 与几家提供商合作，确保这些模型被正确地提供（served）。
  3. 对「模型/提供商」组合做基准测试，得出一份我们真心愿意推荐的名单。

Go、Go Plus 和 Go Teams 都提供这些模型的访问；按使用量选计划即可，要覆盖全团队就选 Go Teams。

设计目标

我们推出 OpenCode Go 是为了：

  1. 用低门槛订阅让 AI 编码对更多人触手可及。
  2. 提供对最好的开源编码模型的稳定可靠访问。
  3. 只收录经过编码智能体场景测试和基准验证的模型。
  4. 零锁定：你依然可以在 OpenCode 里使用任何其他提供商。
