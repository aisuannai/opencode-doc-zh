Harness · Claude Code

Claude Code 讲的是 Anthropic Messages API。用两个环境变量把它指向 Console，就能使用任何付费模型或 Go 模型——包括 GPT、Gemini 和开源模型。对于不接受 Anthropic Messages 的模型，Console 会自动做协议翻译。

💡 扩展

Console CLI 可以一条命令完成 Claude Code 的接入，并附带工作区的策略（policies）、MCP 服务器、Skills 和指令文件：npx @opencode/console setup claude-code。本文其余部分讲的是手动配置的步骤。

bash最短路径：两个环境变量
export ANTHROPIC_BASE_URL="https://opencode.ai/inference/anthropic"
export ANTHROPIC_AUTH_TOKEN="oc_sk_..."
claude --model claude-sonnet-5-5

把 oc_sk_... 替换为个人 API key。

配置（Configure）

把变量写进 ~/.claude/settings.json，这样每个会话都会使用 Console。同时把 opus、sonnet、haiku 三个别名映射到 Console 模型上，让 /model 和后台任务用到的模型也随之生效：

~/.claude/settings.json按量付费
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://opencode.ai/inference/anthropic",
    "ANTHROPIC_AUTH_TOKEN": "oc_sk_...",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "claude-opus-5-5",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "claude-sonnet-5-5",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "claude-haiku-5-5"
  }
}

Claude Code 会自动在 base URL 后面拼接 /v1/messages，所以 base URL 里不要带上这段路径。运行 /status 可以确认 base URL 和 token 是否已生效。

⚠️ 注意

务必使用 ANTHROPIC_AUTH_TOKEN，不是 ANTHROPIC_API_KEY。另外，如果你登录过 Claude 账号，先运行 /logout 再切换，否则 Claude Code 可能把你的 Claude 官方登录凭证一并发给 Console。两个变量选错、或残留官方登录态，是「明明配好了却连不上」的两大主因。

Go 订阅

使用 Go 的 base URL，以及来自订阅了 Go 的工作区的 key：

~/.claude/settings.jsonGo 订阅
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://opencode.ai/inference/go/anthropic",
    "ANTHROPIC_AUTH_TOKEN": "oc_sk_...",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "minimax-m3",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "claude-haiku-5-5"
  }
}

模型（Models）

Console 或 Go 端点表里的任何模型 ID 都可以用。会话中用 /model 切换，或为单次运行指定一个模型：

bash单次运行换模型
claude --model gpt-6.1-sol

🧠 通俗理解

这个配置最妙的地方是「_alias 别名映射」：opus / sonnet / haiku 是 Claude Code 内部按任务轻重挑模型的三个档位（重活、日常、轻活）。把它们分别指向你想要的 Console 模型后，Claude Code 的自动分工逻辑照常运转，只是「演职员表」换成了你工作区里的模型——连后台任务用哪个模型都是你说了算。

Console MCP

为所有项目添加 Console MCP 服务器：

bash
claude mcp add --transport http --scope user opencode-console https://opencode.ai/console/mcp

然后在 Claude Code 里运行 /mcp，选中 opencode-console，在浏览器中完成登录。
