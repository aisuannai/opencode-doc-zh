TUI 命令

这是 opencode 命令行工具的全命令参考：run、mini、session、auth、mcp、serve、service 等每个子命令的用途和常用参数，都在这里。

🧠 通俗理解

把 opencode 想成一个瑞士军刀：TUI 是最常用的那把主刀，其余命令是工具包里的备用刀片——run 用来无界面干活，session 管会话存档，auth 管钥匙，service 管后台引擎。每个命令都支持 --help，忘了参数随时问它。

每个命令都接受 --help 查看完整参数列表，例如 opencode run --help。部分依托服务器的命令支持 --standalone（用私有服务器运行）或 --server <url>（指定服务器）；具体支持哪些参数以各命令的帮助输出为准。

run

发送一条消息并打印回复，不打开交互界面。

bash
$ opencode run "Explain this repository"

CI 中使用

在 CI 里，把提供商 API key 作为 secret 传入，并用 standalone 模式让私有服务器收到它。例如下面这个 GitHub Actions 任务会对检出的仓库做代码审查：

yaml.github/workflows
name: OpenCode review
on: [pull_request]

jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm install --global @opencode/cli
      - run: opencode run --standalone --model anthropic/claude-sonnet-5-5 "Review this repository for correctness and summarize any issues."
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}

指定模型：

bash
$ opencode run --model anthropic/claude-sonnet-5-5 "Refactor parseToken"

继续最近一次会话：

bash
$ opencode run --continue "Now handle the expired case"

为脚本输出按行分隔的 JSON（NDJSON）：

bash
$ opencode run --format json "List the TODO comments"

给消息附加文件：

bash
$ opencode run --file src/server.ts --file src/client.ts "Review these for bugs"

用指定 agent 运行：

bash
$ opencode run --agent build "Fix the failing test"

继续指定的会话：

bash
$ opencode run --session ses_4f2a1c "Check edge cases"

自动批准未被显式拒绝的权限：

bash
$ opencode run --auto "Fix the failing test"

创建时就归档会话，让脚本和 CI 的运行不挤进会话列表和收件箱。会话依然存在：opencode session list 里能看到，也可以按 ID 打开：

bash
$ opencode run --archived "Review this diff"

查看所有子命令和参数：

bash
$ opencode run --help

⚠️ 注意

--auto 会自动批准所有未被权限规则显式拒绝的操作，包括执行命令和改文件。在 CI 里用没问题（环境本来就是一次性的），但在本地开发机上慎用——建议配合 opencode.json 的权限规则先把「红线」划清楚，再用 --auto。

mini

启动极简交互界面，代替全屏 TUI。

bash
$ opencode mini

继续最近一次会话：

bash
$ opencode mini --continue

用指定模型和初始 prompt 启动：

bash
$ opencode mini --model anthropic/claude-sonnet-5-5 --prompt "Summarize this repository"

继续指定的会话：

bash
$ opencode mini --session ses_4f2a1c

查看所有子命令和参数：

bash
$ opencode mini --help

session

管理会话。

bash
$ opencode session list

限制条数并输出 JSON：

bash
$ opencode session list --max-count 20 --format json

删除一个会话及其子会话：

bash
$ opencode session delete ses_9c1b08

把会话数据导出为 JSON：

bash
$ opencode session export ses_4f2a1c

导出时对敏感的对话记录和文件数据做脱敏：

bash
$ opencode session export ses_4f2a1c --sanitize

从 JSON 文件或 URL 导入会话数据：

bash
$ opencode session import session.json

导入到指定目录：

bash
$ opencode session import session.json --directory ~/code/project

查看所有子命令和参数：

bash
$ opencode session --help

auth

管理 AI 提供商和凭据。

bash
$ opencode auth list

以 JSON 形式列出：

bash
$ opencode auth list --format json

登录一个提供商：

bash
$ opencode auth login anthropic

用指定的认证方式登录：

bash
$ opencode auth login anthropic --method key

登出一个已保存的账号：

bash
$ opencode auth logout anthropic work

切换某个集成的激活账号：

bash
$ opencode auth switch anthropic work

导出已保存的凭据，在另一台机器上导入。注意导出文件包含明文密钥：

bash
$ opencode auth export anthropic > credentials.json
$ opencode auth import credentials.json

查看所有子命令和参数：

bash
$ opencode auth --help

models

列出所有可用模型。

bash
$ opencode models

查看所有子命令和参数：

bash
$ opencode models --help

mcp

管理 MCP（Model Context Protocol）服务器。

bash
$ opencode mcp list

添加一个远程服务器：

bash
$ opencode mcp add context7 --url https://mcp.context7.com/mcp

把本地服务器添加到全局配置：

bash
$ opencode mcp add everything --global -- npx -y @modelcontextprotocol/server-everything

添加本地服务器并带一个环境变量：

bash
$ opencode mcp add everything --env LOG_LEVEL=debug -- npx -y @modelcontextprotocol/server-everything

添加远程服务器并带一个请求头：

bash
$ opencode mcp add context7 --url https://mcp.context7.com/mcp --header CONTEXT7_API_KEY=secret

对支持 OAuth 的远程服务器进行认证：

bash
$ opencode mcp auth sentry

移除某服务器已存储的 OAuth 凭据：

bash
$ opencode mcp logout sentry

查看所有子命令和参数：

bash
$ opencode mcp --help

💡 扩展

注意 mcp add 里那个孤立的 --：它之后的整段内容（如 npx -y ...）整体作为启动 MCP 服务器的命令，防止 opencode 把 npx 自己的参数误认为 add 的参数。这是命令行工具传递「原生命令」的通用惯例。MCP 的更多玩法见 MCP 服务器一章。

plugin

管理插件。

bash
$ opencode plugin list

把内置的服务器插件也列进来：

bash
$ opencode plugin list --builtin

安装一个插件并加入全局配置：

bash
$ opencode plugin add @example/opencode-tui

检查包型插件是否有更新：

bash
$ opencode plugin check

更新包型插件：

bash
$ opencode plugin update

从全局配置移除一个插件：

bash
$ opencode plugin remove @example/opencode-tui

查看所有子命令和参数：

bash
$ opencode plugin --help

stats

显示可分享的使用统计。

bash
$ opencode stats

只看最近 7 天：

bash
$ opencode stats --days 7

看模型用量：

bash
$ opencode stats --models

看费用和 token 明细：

bash
$ opencode stats --cost

打印 JSON 而不是报告：

bash
$ opencode stats --json

只统计当前项目：

bash
$ opencode stats --project .

查看所有子命令和参数：

bash
$ opencode stats --help

serve

启动 API 和 Web 服务器。详见Web 界面一页。

bash
$ opencode serve

绑定所有网卡并使用固定端口：

bash
$ opencode serve --hostname 0.0.0.0 --port 4096

允许来自其它域名的浏览器客户端：

bash
$ opencode serve --cors https://app.example.com

查看所有子命令和参数：

bash
$ opencode serve --help

pair

打印一次性连接链接（附第一个链接的二维码），用于把浏览器或 App 登录进服务器。链接 5 分钟后过期，且只能使用一次。

bash
$ opencode pair

在链接中使用外部 URL：

bash
$ opencode pair --url https://dev.example.com

通过 OpenTunnel 远程地址从任何地方配对。这会把服务器暴露到互联网，所以第一次开启远程访问时它会说明这一点并请你确认。详见Web 界面的远程访问部分：

bash
$ opencode pair --remote

跳过确认直接接受，例如在没有终端的脚本中：

bash
$ opencode pair --remote --yes

查看所有子命令和参数：

bash
$ opencode pair --help

service

管理后台服务器。详见Web 界面一页。

bash
$ opencode service start

重启：

bash
$ opencode service restart

查看状态：

bash
$ opencode service status

停止：

bash
$ opencode service stop

读取一项设置：

bash
$ opencode service get hostname

设置一项：

bash
$ opencode service set hostname 0.0.0.0

增加一个允许的 CORS 域名：

bash
$ opencode service set cors https://app.example.com

给服务器进程传递一个环境变量：

bash
$ opencode service set env OPENCODE_LOG_LEVEL DEBUG

把某项设置恢复为默认值：

bash
$ opencode service unset hostname

查看所有子命令和参数：

bash
$ opencode service --help

reload

不重启服务器热重载配置。正在运行的会话会在下一个步骤边界继续使用刷新后的服务：

bash
$ opencode reload

api

向正在运行的服务器发起请求。

bash
$ opencode api GET /api/session

用查询参数调用一个操作 ID：

bash
$ opencode api session.list --param limit=10

发送 JSON 请求体：

bash
$ opencode api session.create --data '{"title": "New session"}'

添加请求头：

bash
$ opencode api GET /api/session -H "accept: application/json"

查看所有子命令和参数：

bash
$ opencode api --help

💡 扩展

opencode api 既支持裸 HTTP 路径（GET /api/session），也支持操作 ID（如 session.list）——后者来自官方 OpenAPI 规范，写法更稳定且自带参数补全的可能。想看完整端点清单，见 HTTP API 参考。

acp

通过 stdin 和 stdout 启动一个 Agent Client Protocol 服务器，供编辑器集成使用。它会一直运行，直到客户端关闭连接：

bash
$ opencode acp

查看所有子命令和参数：

bash
$ opencode acp --help

ACP 的详细介绍见ACP一页。

debug

提供调试和故障排查工具。

bash
$ opencode debug agents

列出配置来源：

bash
$ opencode debug config

给运行中的后台服务器写一份堆快照并打印路径：

bash
$ opencode debug heap-dump

把快照写进指定目录：

bash
$ opencode debug heap-dump --directory ./snapshots

显示全局路径：

bash
$ opencode debug paths

打印单个路径：

bash
$ opencode debug paths db

查看所有子命令和参数：

bash
$ opencode debug --help

upgrade

升级 OpenCode 到最新版或指定版本。别名：update。

bash
$ opencode upgrade

升级到指定版本并使用指定的包管理器：

bash
$ opencode upgrade 2.0.21 --method bun

查看所有子命令和参数：

bash
$ opencode upgrade --help

uninstall

停止后台服务、移除全局缓存并卸载 OpenCode。会话数据、配置和状态不会被删除：

bash
$ opencode uninstall

预览将被删除的内容：

bash
$ opencode uninstall --dry-run

查看所有子命令和参数：

bash
$ opencode uninstall --help
