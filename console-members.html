成员

所有者（Owner）和管理员（Admin）在 Settings › Members 页管理人员。点开一位成员，可以查看他的用量和预算策略。

邀请成员

  1. 打开 Settings › Members，点击 Invite Members。
  2. 添加一个或多个邮箱地址。可以用空格、逗号或分号分隔，也可以直接粘贴一整份名单。
  3. 点击 Send invitations。

每个人都会收到一封标题为 Join Acme Inc. on OpenCode 的邮件，内含 Join workspace 按钮。

邀请 7 天后过期。所有人加入时都是 Member 角色；等他们加入后再调整角色。

⚠️ 注意

在 OpenCode Go 和 Go Plus 计划下，你邀请进来的人只能用免费模型或工作区余额，不会自动获得你的 Go 额度。要让每个人都拥有独立的 Go 上限，请升级到 Go Teams（$20/成员/月，最少 2 名成员）。第二位成员之后，每位成员从加入当月起每月收 $20。

成员也可以自动加入：

  • SSO——在你已验证的邮箱域名下，新用户首次登录时自动加入。
  • 目录同步（Directory sync）——你在身份提供商（IdP）里指派或移除人员时，Console 自动增删成员。

接受邀请

受邀者必须用收到邀请的那个邮箱地址登录。接受邀请有两种方式：

  • 点击邀请邮件中的 Join workspace，然后登录或注册账号。
  • 登录 Console，打开工作区菜单，在 Pending invitations 下点击 Join。

如果他们用别的账号登录，Console 会要求他们 Sign out and continue（退出并用受邀邮箱继续）。

🧠 通俗理解

邀请是「认邮箱不认人」的：邮件发给谁的邮箱，就得用那个邮箱的账号进。这样能防止你把 A 的邮箱地址手滑填成 B，结果 B 混进了团队。如果你的邀请名单里邮箱写错了，直接在待处理邀请里吊销重发即可。

管理待处理邀请

待处理邀请会出现在 Members 表中，显示为 Pending · Expires 加日期，或 Expired（已过期）。

操作方式
重发（Resend）⋯ › Resend invitation。发送一个新的 7 天有效链接；旧链接随即失效。
吊销（Revoke）⋯ › Remove...。链接立即失效。

修改角色

打开成员所在行的角色菜单，选择 Member、Admin 或 Owner。

你只能授予不高于自己的角色，且工作区始终至少保留一名所有者。见 Roles。

移除成员

  1. 点击成员所在行的 ⋯ › Remove...。
  2. 点击 Remove member 确认。

其访问权限立即被吊销，之后你仍可以再次邀请他。他过去的使用记录会留在工作区报表里。

移除成员还会吊销他在该工作区创建的所有 API key，包括服务账号的 key。服务账号本身会保留，其他人创建的 key 继续有效。见 Revocation。

💡 扩展

「移除成员会连带吊销他创建的 key」是一条重要的安全设计：避免「人走了，key 还在自动跑」的幽灵调用。但注意反向推论——别把重要的长期服务账号 key 交给某个具体成员去创建，否则他离职时这条 key 也会一起断，生产线上的自动化任务会突然报 401。服务账号的创建和 key 管理最好由 Admin 亲自操作。

成员详情

点击一位成员，可以查看他的月度预算、使用的模型和客户端、用量图表和请求日志。在这里你可以为他设置预算，并把他的用量导出为 CSV。
