快捷键

OpenCode TUI 的所有按键行为都可以在 cli.json 的 keybinds 里自定义。本页列出全部命令 ID 和默认绑定，想改哪个就覆盖哪个。

自定义方式

cli.json
{
  "keybinds": {
    "leader": "ctrl+space",
    "command.palette.show": "ctrl+k",
    "app.exit": ["ctrl+c", "ctrl+d"],
    "app.debug": false
  },
  "leader": {
    "timeout": 1500
  }
}

单个按键用字符串：

cli.json
{
  "keybinds": {
    "command.palette.show": "ctrl+k"
  }
}

多个备选按键用逗号分隔（或写成数组）：

cli.json
{
  "keybinds": {
    "app.exit": "ctrl+c,ctrl+d"
  }
}

用 "none" 或 false 禁用某个绑定：

cli.json
{
  "keybinds": {
    "app.debug": "none",
    "help.show": false
  }
}

用对象形式可以精细控制按键事件行为：

cli.json
{
  "keybinds": {
    "prompt.paste": {
      "key": "ctrl+v",
      "preventDefault": false
    }
  }
}

前导键（leader）默认是 Ctrl+X。其它绑定里的 <leader> 指的就是这个键：

cli.json
{
  "keybinds": {
    "leader": "ctrl+space",
    "model.list": "<leader>m"
  },
  "leader": {
    "timeout": 2000
  }
}

未知的命令 ID 会被忽略。

🧠 通俗理解

前导键就像 vim 里的「先按键再按字母」组合拳：Ctrl+X 相当于喊一声「预备——」，接下来按 M 就是「列出模型」、按 N 就是「新会话」。把大量组合挂在一个前缀键下，等于把两层快捷键空间叠在一起，既不挤占单键，又好记（M=Model、N=New、L=List）。改成 ctrl+space 只需要一处，所有 <leader> 组合跟着变。

⚠️ 注意

覆盖绑定是「整体替换」而不是「追加」：把 app.exit 改成 ["ctrl+c"] 后，默认的 Ctrl+D 和 <leader>q 就都不再退出程序了。另外注意 leader 超时（leader.timeout，默认毫秒数）——按完前导键后超时未按下一个键，组合就作废，键位有延迟的远程终端可以把这个值调大。

Diff 查看器

按 d（diff.switch_source）可以选择 All、Committed、Uncommitted 或 Last turn（会话内），或选择 Base 更改对比分支。选择会一直保留到 TUI 退出。初始范围可用 cli.json 的 diffs.source 设置。

滚动、翻页和开头/结尾快捷键始终作用于 diff 视图本身。键盘焦点不可切换：点击文件打开它，点击文件夹展开或收起，用鼠标滚轮滚动文件树。

用 n / p 或 alt+down / alt+up（macOS 上是 Option 键）在文件之间移动。在 diff 查看器内部，Alt 组合键导航的是文件而非会话标签页。

按 m 把文件标记为已审查并折叠它的补丁正文。在全部文件视图里再按一次 m 可取消标记并重新展开补丁。单文件视图里，标记已审查后会自动跳到下一个文件，但停在最后一个文件不会回绕；取消标记永远不会自动前进。

在侧边栏或 diff 标题上右键点击文件，可选 Mark complete（或 Mark incomplete）。这改变的是和 m 相同的已审查状态。从菜单里标记其它文件为完成，既不会选中它，也不会让当前阅读的文件前进。

带 Shift 的 diff.help 备选按键是为了兼容那些在按下 ? 时会报告 Shift 修饰键的终端。

💡 扩展

「逻辑行」和「可视行」的区别来自编辑器的老传统：当一行太长在屏幕上折成多行显示时，Ctrl+E（logical end）一步跳到整行的真正末尾，而 Alt+E（visual end）只跳到当前屏幕行的末尾。写长 prompt、在窗口边缘来回跳时会明显感觉到差别。super 指 macOS 的 Command 键。
