Harness · Raycast

通过 OpenCode 扩展，你可以在 Raycast 的 AI Chat、Quick AI 和 AI Commands 中使用 Console 和 Go 的模型。由扩展提供的模型需要 Raycast Pro 订阅。

🧠 通俗理解

Raycast 的接入方式和前面几个 Harness 不一样：它不是命令行工具，而是一个 macOS 启动器应用，靠「扩展（extension）」机制接入。装上扩展、填一个 key，Console 里启用的模型就会出现在 Raycast 的模型选择器里，用量全部计入你的工作区。换句话说，你平时按 ⌥ Space 唤起的那条「命令栏」也能用上工作区的 Claude、GPT、Gemini 等模型。

配置（Configure）

扩展会加载你工作区中已启用的模型，并把用量计入该工作区。付费模型和 Go 模型都可以选；免费档 chat 模型要求使用 OpenCode，从 Raycast 调用会返回 HTTP 403。

  1. 从 Raycast Store 安装扩展。
  2. 创建一个个人 API key，粘贴到扩展的 API Key 偏好设置里。
  3. 在 Raycast 的模型选择器里，允许扩展提供模型。

在 Console 里启用或停用模型之后，运行 Refresh Models 刷新列表：

textRaycast 命令
Refresh Models

Go 订阅

使用来自订阅了 Go 的工作区的 key。之后扩展会在模型选择器里列出 Go 的模型。

Console MCP

用 Install MCP Server 命令添加 Console MCP 服务器：

字段值
Transport（传输方式）HTTP
URLhttps://opencode.ai/console/mcp
OAuth Type（OAuth 类型）Dynamic（动态）

Raycast 第一次使用该服务器时会要求你登录。

💡 扩展

和其它 Harness 页面相比，Raycast 这一页的 CLI 步骤最少——因为 Raycast 本身是图形界面，安装扩展、粘贴 key、勾选模型都在 UI 里完成，不需要 npx @opencode/console setup 命令。它同样支持 Console MCP（走 OAuth 动态注册），但触发登录的时机是「第一次实际用到这个服务器」，而不是添加时。
