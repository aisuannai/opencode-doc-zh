Effect RPC

Effect 插件可以暴露返回类型化 Effect 和 Stream 的方法与事件。

这是 插件 RPC 的 Effect 版本：契约定义改用 Effect Schema，实现是 Effect，事件订阅是 Stream。

定义（Define）

用 Rpc.define 加 Effect Schema 定义 RPC：

src/rpc.tsTypeScript
import { Rpc } from "@opencode/plugin/rpc"
import { Schema } from "effect"

export const Acme = Rpc.define({
  id: "acme",
  methods: {
    search: {
      input: Schema.Struct({ query: Schema.String }),
      output: Schema.Struct({ text: Schema.String }),
      errors: {
        not_found: Schema.Struct({ query: Schema.String }),
      },
    },
  },
  events: {
    updated: {
      schema: Schema.Struct({ itemID: Schema.String, text: Schema.String }),
    },
  },
})

校验（Validation）

Effect Schema 校验值并推断它们的 TypeScript 类型：

TypeScript
input: Schema.Struct({ query: Schema.String })

JSON Schema 和 Standard Schema 同样受支持。

输入与输出（Input and output）

input 用于方法参数，output 用于返回值。没有值时任一都可以省略：

TypeScript
search: {
  input: Schema.Struct({ query: Schema.String }),
  output: Schema.Struct({ text: Schema.String }),
}

错误（Errors）

把预期失败加进 errors。每个键成为错误的 type：

TypeScript
errors: {
  not_found: Schema.Struct({ query: Schema.String }),
}

事件（Events）

把事件加进顶层的 events 映射。事件数据必须是对象：

TypeScript
events: {
  updated: {
    schema: Schema.Struct({ itemID: Schema.String, text: Schema.String }),
  },
}

实现（Implement）

从插件 Effect 里注册实现：

src/index.tsTypeScript
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"
import { Acme } from "./rpc.js"

export default Plugin.define({
  id: "acme-effect-plugin",
  effect: (ctx) =>
    Effect.gen(function* () {
      const registration = yield* ctx.rpc.register(Acme, {
        search: ({ query }, context) =>
          findText(query).pipe(
            Effect.flatMap((text) =>
              text
                ? Effect.succeed({ text })
                : Effect.fail(context.error("not_found", "Result not found", { query })),
            ),
          ),
      })

      const acme = ctx.rpc(Acme)
      const result = yield* acme.search({ query: "hello" })

      yield* registration.events.emit("updated", { itemID: "item-1", text: result.text })
    }).pipe(Effect.orDie),
})

错误映射会成为每个方法 Effect 的错误类型。用 context.error(...) 创建已声明的错误。

调用（Call）

RPC 注册之后，可以通过 HTTP 或从另一个插件调用它。

HTTP

创建 Effect 客户端，然后创建 RPC 子客户端：

TypeScript
import { OpenCode } from "@opencode/client/effect"
import { Effect } from "effect"
import { FetchHttpClient } from "effect/http"
import { Acme } from "opencode-acme-plugin/rpc"

const program = Effect.gen(function* () {
  const client = yield* OpenCode.make({ baseUrl: "http://localhost:4096" })
  const acme = client.rpc(Acme)
  return yield* acme.search({ query: "hello" })
})

const result = await Effect.runPromise(program.pipe(Effect.provide(FetchHttpClient.layer)))

插件（Plugin）

另一个 Effect 插件可以从它的上下文创建本地子客户端：

TypeScript
import { Effect } from "effect"

effect: (ctx) =>
  Effect.gen(function* () {
    const acme = ctx.rpc(Acme)
    const result = yield* acme.search({ query: "hello" })
    yield* Effect.logInfo(result.text)
  }).pipe(Effect.orDie)

订阅（Subscribe）

RPC 事件是 Stream。按事件名订阅，并在作用域 fiber 里运行该 Stream：

TypeScript
import { Effect, Stream } from "effect"

const acme = ctx.rpc(Acme)

yield* acme.events.subscribe("updated").pipe(
  Stream.runForEach((event) => Effect.logInfo(event.data.text)),
  Effect.forkScoped,
)

订阅是「活性」的（live only），Stream 消费停止时即关闭。

⚠️ 注意

定义契约（src/rpc.ts）时别忘了发布配置：其它插件和客户端要按 opencode-acme-plugin/rpc 这样的子路径导入它，你的 package.json exports 里必须有 "./rpc": "./src/rpc.ts" 这一条，否则调用方类型解析不到。

💡 扩展

对比一下两套 RPC 的订阅语义：Promise 版用 events.on(...) 回调加取消函数，Effect 版直接 forkScoped 一个 Stream 消费——fiber 结束订阅就结束，正好借作用域自动清理。定义契约部分（Rpc.define）两边其实是同一个 API，只是 schema 写法不同：JSON Schema ↔ Effect Schema。
