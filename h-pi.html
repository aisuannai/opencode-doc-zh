Harness · Pi

Pi 内置了 OpenCode 的按量付费和 Go 两个提供商。它会为每个付费或 Go 模型自动挑选合适的 API。免费档 chat 模型要求使用 OpenCode，从 Pi 调用会返回 HTTP 403。

💡 扩展

Console CLI 可以一条命令完成 Pi 的接入，并附带工作区的策略（policies）、MCP 服务器、Skills 和指令文件：npx @opencode/console setup pi。本文其余部分讲的是手动配置的步骤。

提供商套餐
opencode按量付费（Pay-as-you-go）
opencode-goGo

配置（Configure）

两个提供商都从环境变量 OPENCODE_API_KEY 读取 key。先创建一个个人 API key：

bash
export OPENCODE_API_KEY="oc_sk_..."
pi --model opencode/claude-sonnet-5-5

也可以在 Pi 里运行 /login 并选择提供商。Pi 会把 key 存到 ~/.pi/agent/auth.json：

text在 Pi 内登录
/login opencode

Go 订阅

使用 opencode-go 提供商，以及来自订阅了 Go 的工作区的 key：

bash
pi --model opencode-go/kimi-k3

模型（Models）

以 <provider>/<model-id> 的格式选择模型，ID 来自 Console 或 Go 端点表。用 --list-models 列出 Pi 已知的模型：

bash列出已知模型
pi --list-models opencode-go

在 ~/.pi/agent/settings.json 里设置默认值，或在 /model 选择器里按 Ctrl+S 设为默认：

~/.pi/agent/settings.json默认模型
{
  "defaultProvider": "opencode-go",
  "defaultModel": "kimi-k3"
}

⚠️ 注意

Console 上新了某个模型但 Pi 里看不到？运行 pi update --models 刷新模型列表即可。Pi 本地缓存了一份模型目录，不会实时跟着 Console 变。

Console MCP

Pi 从 v0.99.0 起支持 MCP。添加 Console MCP 服务器，然后在浏览器中完成登录：

bash
pi mcp add opencode-console --url https://opencode.ai/console/mcp
pi mcp login opencode-console

🧠 通俗理解

Pi 的模型名写法是「提供商/模型」两段式：opencode/claude-sonnet-5-5 表示用 OpenCode 的按量付费通道跑 Claude Sonnet，opencode-go/kimi-k3 则表示用 Go 订阅的通道跑 Kimi。同一个模型可能同时存在于两个通道，前缀决定走哪条账——按量付费从工作区余额扣钱，Go 从订阅额度里扣。
