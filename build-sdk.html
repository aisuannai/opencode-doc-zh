SDK

@opencode/sdk 把 OpenCode 直接托管在你的应用内部。与网络客户端不同，它把 OpenCode 服务器组装起来，并在内存中通过其 HTTP 路由器转发 API 调用。它不打开任何 HTTP 监听器，客户端与服务器之间也没有网络跳转。

🧠 通俗理解

客户端（@opencode/client）是「打电话给 OpenCode」，SDK 是「把 OpenCode 装进你的进程里」。SDK 内部仍然跑着一个完整的 OpenCode 服务器，只是 API 调用不经过网卡，而是在内存里直接递进路由器——更快、更可控，也适合无服务器环境。想在 Cloudflare Durable Object 里用，见 Cloudflare SDK。

安装

sh
bun add @opencode/sdk

创建宿主（host）

OpenCode.create() 返回一个显式拥有的宿主。用 await using 来释放它的路由器、Location 服务、fiber 和作用域内的插件注册：

TypeScript
import { OpenCode } from "@opencode/sdk"

await using opencode = await OpenCode.create()
const session = await opencode.sessions.create({
  location: { directory: "/workspace" },
})

await opencode.sessions.prompt({
  sessionID: session.id,
  text: "Review the current changes",
})

当显式资源管理不可用时，显式调用 await opencode.close()。

嵌入式宿主使用与 @opencode/client 相同的 Promise 值、已声明错误、请求选项和 AsyncIterable 流。它暴露完整的生成客户端，并为会话和事件组额外提供 sessions 和 events 便捷别名。

工作树（Worktrees）

工作树操作需要 projectID。create 和 refresh 从项目保存的规范检出（canonical checkout）加载配置和插件。list 只读已保存的清单；remove 会激活规范插件并使用记录的策略，策略不可用时失败：

TypeScript
const projectID = session.projectID
const worktree = await opencode.worktree.create({ projectID, name: "task" })
await opencode.worktree.refresh({ projectID })
await opencode.worktree.remove({ projectID, directory: worktree.directory, force: false })

refresh 会用所有可用策略在已知检出根目录间发现工作树。通过插件的工作树转换注册自定义策略。

流式事件（Stream events）

TypeScript
for await (const event of opencode.events.subscribe()) {
  console.log(event.type)
}

通过生成的请求选项传一个 AbortSignal，或者直接结束迭代来取消它的响应体。

定制（Customize）

通过注册插件定制你的 OpenCode 实例。把插件传给 OpenCode.create()，在嵌入式宿主启动时定制 agents、模型、工具和其它行为：

TypeScript
import { Plugin } from "@opencode/plugin"
import { OpenCode } from "@opencode/sdk"

const plugin = Plugin.define({
  id: "customize-agent",
  async setup(ctx) {
    await ctx.agent.transform((agents) => {
      agents.update("build", (agent) => {
        agent.description = "Builds features and fixes bugs for our team"
      })
    })
  },
})

await using opencode = await OpenCode.create({ plugins: [plugin] })

启动后用 await opencode.plugin(plugin) 注册另一个插件。

💡 扩展

SDK 场景下，插件通常和你的应用代码在同一个构建产物里，直接以 Plugin.define(...) 的对象传入即可，不需要 opencode.json 里的 plugins 配置。插件的钩子、转换、工具和完整上下文见服务器插件全篇。
