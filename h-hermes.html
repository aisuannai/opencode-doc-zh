Harness · Hermes

Hermes Agent 内置了 OpenCode 的按量付费和 Go 两个提供商。它会为每个付费或 Go 模型自动挑选合适的 API。免费档 chat 模型要求使用 OpenCode，从 Hermes 调用会返回 HTTP 403。

💡 扩展

Console CLI 可以一条命令完成 Hermes 的接入，并附带工作区的策略（policies）、MCP 服务器、Skills 和指令文件：npx @opencode/console setup hermes。本文其余部分讲的是手动配置的步骤。

提供商套餐Key 环境变量
opencode-zen按量付费（Pay-as-you-go）OPENCODE_ZEN_API_KEY
opencode-goGoOPENCODE_GO_API_KEY

🧠 通俗理解

和 Claude Code / Codex 不同，Hermes 属于「内置支持」阵营：它把 OpenCode Console 当成两个官方提供商直接集成进配置流程，不用你手写 base URL、也不用手动声明协议——「它为每个模型挑对 API」意味着协议翻译这一步也由 Hermes 侧完成。你只需要提供 key 和选模型。

配置（Configure）

运行模型设置命令，按量付费选 OpenCode Zen，Go 套餐选 OpenCode Go：

bash
hermes model

粘贴一个个人 API key，然后选择模型。Hermes 会把 key 保存到 ~/.hermes/.env，把选择保存到 ~/.hermes/config.yaml：

~/.hermes/config.yaml选择结果示例
model:
  provider: opencode-go
  default: kimi-k3

⚠️ 注意

Go 套餐要求每个请求都带会话 ID（session ID）。Hermes 从 v0.21.6 起会自动发送它。如果你用的版本更旧，请求可能被拒绝——先升级 Hermes，再接 Go。

模型（Models）

使用 Console 或 Go 端点表里的模型 ID，不带前缀。会话中用 /model 切换，或为单次运行指定：

bash单次运行指定提供商和模型
hermes chat --provider opencode-zen --model claude-sonnet-5-5

Console MCP

用 OAuth 方式添加 Console MCP 服务器，然后在浏览器中完成登录：

bash
hermes mcp add opencode-console --url https://opencode.ai/console/mcp --auth oauth
hermes mcp login opencode-console

也可以直接写进 ~/.hermes/config.yaml，然后在会话里运行 /reload-mcp 生效：

~/.hermes/config.yamlMCP 配置
mcp_servers:
  opencode-console:
    url: https://opencode.ai/console/mcp
    auth: oauth
