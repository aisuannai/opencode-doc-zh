# OpenCode 中文文档 · 教程版

[OpenCode](https://opencode.ai/docs) 官方文档的中文教程版，纯静态 HTML，零依赖、零构建。

- **内容零遗漏**：覆盖官方文档全部 71 页（入门 / 配置 / CLI / 构建与集成 / API / Console / Harnesses）
- **教程化翻译**：不是干巴巴的直译，配有 🧠 通俗理解 / ⚠️ 注意 / 💡 扩展 三类注解
- **沉浸式阅读设计**：深夜终端 × 纸感阅读双主题、阅读进度条、侧边目录、本页目录、上一页/下一页

## 本地阅读

双击 `index.html` 即可，任何现代浏览器都能打开，无需服务器。

## 更新文档

官方文档更新后，对应翻译 `opencode.ai/docs` 相应页面并更新本目录下的同名 HTML，push 即可自动部署（若已配置自动部署）。
